# AI Language Academy

Δοκιμαστική εφαρμογή για ελληνόφωνους ενήλικες που ξεκινούν Αγγλικά. Συνδυάζει οργανωμένα μικρά μαθήματα, εκπαιδευτικό πίνακα, γραπτές απαντήσεις, αποθήκευση του σημείου συνέχειας και προγραμματισμένες επαναλήψεις.

Η έκδοση αυτή είναι ιδιωτικό πρωτότυπο. Ο δοκιμαστικός καθηγητής χρησιμοποιεί προκαθορισμένες ελληνικές εξηγήσεις. Δεν έχει ακόμη συνδεθεί υπηρεσία ελεύθερου διαλόγου AI και δεν έχουν ενεργοποιηθεί πληρωμές.

## Εκκίνηση

Απαιτείται Python 3.12 ή νεότερη. Δεν χρειάζεται εγκατάσταση εξωτερικών βιβλιοθηκών ή λογαριασμός σε πάροχο AI.

Οι καθημερινές σειρές της ελληνικής δοκιμής υπολογίζονται με την ώρα Αθήνας. Περιλαμβάνεται εναλλακτικό αρχείο ζώνης ώρας IANA 2026b, ώστε να μη χρειάζεται πρόσθετο πακέτο όταν το λειτουργικό δεν παρέχει βάση ζωνών, όπως συχνά συμβαίνει στα Windows. Η εναλλακτική διαδρομή ελέγχθηκε αυτοματοποιημένα· πραγματική εκτέλεση σε Windows/macOS παραμένει προς δοκιμή.

Στο προετοιμασμένο cloud περιβάλλον:

```sh
cd /workspace/-
python3 server.py
```

Ο server ακούει από προεπιλογή στη διεύθυνση `127.0.0.1`, θύρα `8000`. Η βάση δεδομένων φυλάσσεται έξω από το αποθετήριο, στο `/workspace/academy-data/academy.sqlite3`. Τα `HOST`, `PORT` και `ACADEMY_DB` αλλάζουν τις αντίστοιχες ρυθμίσεις. Δεν δημοσιεύουμε τον δοκιμαστικό server στο Internet.

Η νέα έκδοση χρησιμοποιεί την ίδια βάση και προσθέτει αυτόματα τα δεδομένα συνέχειας/επανάληψης κατά την εκκίνηση. Δεν διαγράφουμε την υπάρχουσα βάση για αναβάθμιση. Τα ήδη ολοκληρωμένα μαθήματα εμφανίζονται και στις επαναλήψεις.

Για να τη δεις στον δικό σου υπολογιστή, κατέβασε και αποσυμπίεσε το πακέτο `ai-language-academy.zip`. Χρειάζεται εγκατεστημένη Python 3.12 ή νεότερη. Στα Windows κάνε διπλό κλικ στο `start-windows.bat`. Σε macOS/Linux άνοιξε τερματικό στον αποσυμπιεσμένο φάκελο και εκτέλεσε:

```sh
python3 launch.py
```

Το πρόγραμμα ανοίγει τον browser αυτόματα. Κράτησε το παράθυρο εκκίνησης ανοιχτό όσο δοκιμάζεις την εφαρμογή· το κλείσιμο ή το Ctrl+C σταματά τον server. Αν ο browser δεν ανοίξει, γράψε `127.0.0.1:8000` στη γραμμή διεύθυνσης. Η βάση αποθηκεύεται στον φάκελο `academy-data` δίπλα στον φάκελο του έργου. Το `ACADEMY_DB` μπορεί να ορίσει άλλη τοπική θέση.

Η διεύθυνση του cloud server δεν ανοίγει αυτόματα από τον υπολογιστή σου· η οθόνη onboarding δεν παρέχει δημόσια προεπισκόπηση localhost. Η τοπική εκκίνηση δεν παρέχει πρόσβαση από δεύτερη πραγματική συσκευή. Η δημόσια φιλοξενία και το HTTPS είναι επόμενο, ξεχωριστό βήμα.

## Πρώτη δοκιμή

1. Επίλεξε εγγραφή και χρησιμοποίησε δοκιμαστικό email και νέο κωδικό που δεν χρησιμοποιείς αλλού. Δεν αποστέλλεται email επιβεβαίωσης.
2. Δήλωσε ότι είσαι ενήλικος και επίλεξε Ελληνικά → Αγγλικά, στόχο και ημερήσιο χρόνο.
3. Άνοιξε το πρώτο διαθέσιμο μάθημα από τον χάρτη.
4. Διάβασε τις εξηγήσεις και απάντησε στις ασκήσεις. Δοκίμασε και μια λανθασμένη απάντηση για να δεις τη διόρθωση.
5. Ολοκλήρωσε το μάθημα, αποσυνδέσου και συνδέσου ξανά. Η πρόοδος διατηρείται στη βάση του server.
6. Από τις ρυθμίσεις μπορείς να εξαγάγεις τα δεδομένα ή να διαγράψεις τον δοκιμαστικό λογαριασμό.

Η φωνή είναι προαιρετική και εξαρτάται από τον browser και τις εγκατεστημένες φωνές. Η αναγνώριση ομιλίας, όπου προσφέρεται, μπορεί να στέλνει ήχο στον πάροχο του browser και απαιτεί ξεχωριστή ενημερωμένη επιλογή. Υπάρχει πάντα πληκτρολόγηση. Δεν γίνεται επιστημονική αξιολόγηση προφοράς.

## Δοκίμασε τη συνέχεια και τις επαναλήψεις

Άνοιξε ένα μάθημα και προχώρησε στη δεύτερη κάρτα. Ανανέωσε τη σελίδα ή γύρισε στον χάρτη και ξανά στο ίδιο μάθημα: εμφανίζεται η αποθηκευμένη θέση. Οι σωστές απαντήσεις αποθηκεύονται επίσης, ώστε να συνεχίζεις από την ίδια άσκηση. Αν δεν επιβεβαιωθεί η αποθήκευση, εμφανίζεται μήνυμα και μπορείς να ξαναπατήσεις το ίδιο κουμπί.

Μετά την ολοκλήρωση ενός μαθήματος, επίλεξε **Επαναλήψεις → Εξάσκηση όλων**. Έτσι δοκιμάζεις αμέσως τις ασκήσεις που έχεις μάθει. Η επιλογή **Για τώρα** δείχνει όσες έφτασαν στην προγραμματισμένη ώρα τους· ένα νέο μάθημα επιστρέφει αρχικά μετά από μία ημέρα, οπότε η λίστα μπορεί να είναι άδεια σήμερα.

Οι σωστές προγραμματισμένες απαντήσεις αυξάνουν σταδιακά τα διαστήματα σε 1, 3, 7, 14 και 30 ημέρες. Σωστή πρόωρη εξάσκηση κρατά την υπάρχουσα ημερομηνία. Λάθος απάντηση εμφανίζει τη διόρθωση και φέρνει νέα επανάληψη σε 10 λεπτά. Δεν προστίθενται XP από τις επαναλήψεις και οι ώρες εμφανίζονται σε ώρα Ελλάδας.

## Τεχνικός έλεγχος

```sh
python3 -m unittest discover -s tests -v
```

Οι δοκιμές χρησιμοποιούν προσωρινή βάση και δεν πρέπει να αλλάζουν τους πραγματικούς λογαριασμούς. Η τρέχουσα κατάσταση επαλήθευσης βρίσκεται στο `TEST_PLAN.md`.

Προαιρετικός πλήρης έλεγχος με πραγματικό Chromium:

```sh
python3 tests/browser_smoke.py
python3 tests/browser_learning.py
```

Αυτός ο έλεγχος χρειάζεται Playwright και Chromium, ήδη εγκατεστημένα στο προετοιμασμένο cloud περιβάλλον. Δεν αποτελούν εξαρτήσεις για την απλή λειτουργία της εφαρμογής. Σε άλλη εγκατάσταση το `CHROMIUM_PATH` ορίζει τη θέση του εκτελέσιμου Chromium.

Στην τελική εκτέλεση της **πρώτης έκδοσης** πέρασαν και τα **16 backend tests**. Πέρασε επίσης η ροή Chromium σε desktop και προσομοιωμένα πλάτη κινητού 320/390 px: εγγραφή, και τα τρία μαθήματα, διόρθωση λάθους, 100 XP, αλλαγές ρυθμίσεων, εξαγωγή, επανεκκίνηση server, είσοδος από νέο browser με διατηρημένη πρόοδο, αποσύνδεση και διαγραφή λογαριασμού. Δεν εμφανίστηκαν σφάλματα JavaScript. Ξεχωριστός έλεγχος επιβεβαίωσε διατήρηση προόδου μετά από τερματισμό και εκκίνηση νέου Python process. Η πραγματική φωνή, οι φυσικές κινητές συσκευές και η εγκατάσταση PWA χρειάζονται επιπλέον έλεγχο.

Στο νέο ορόσημο πέρασαν **26 backend tests σε 17,097 δευτερόλεπτα**, η πλήρης επανεκτέλεση του `browser_smoke.py` και ο νέος έλεγχος `browser_learning.py`: συνέχεια κάρτας/άσκησης μετά από ανανέωση ή νέα ανεξάρτητη συνεδρία browser, σωστός χειρισμός αποτυχίας αποθήκευσης, επαναλήψεις χωρίς XP και ασφαλής επαναποστολή όταν χάνεται η απάντηση του server. Πέρασαν επίσης έλεγχοι εμφάνισης επανάληψης στα 320 px και ενημέρωσης του χάρτη όταν η απάντηση ολοκλήρωσης φτάνει μετά από αλλαγή σελίδας. Δεν εμφανίστηκαν σφάλματα JavaScript runtime· τα σκόπιμα σφάλματα δικτύου του `browser_learning.py` εμφανίζονται αναμενόμενα στην κονσόλα.

## Αποθηκευμένη ρύθμιση cloud

Αποθηκεύτηκαν σε draft οι οδηγίες εκκίνησης (`start_skill`), η δήλωση του υπάρχοντος αποθετηρίου και τέσσερα domains δημόσιας έρευνας: `www.duolingo.com`, `blog.duolingo.com`, `openai.com`, `ai.google.dev`. Δεν χρειάζεται script εγκατάστασης για τον βασικό server, επειδή χρησιμοποιεί τη standard library της Python.

Οι οδηγίες `start_skill` ενημερώθηκαν και αποθηκεύτηκαν επιβεβαιωμένα για τη συνέχεια μαθήματος και τις επαναλήψεις, διατηρώντας τις προηγούμενες οδηγίες. Περιλαμβάνουν τον νέο έλεγχο `python3 tests/browser_learning.py`. Η τρέχουσα εφαρμογή επανεκκινήθηκε με τη νέα έκδοση και αναβαθμίζει την υπάρχουσα βάση κατά την εκκίνηση.

Το draft δεν έχει δημοσιευθεί και η αποθήκευσή του δεν ενεργοποιεί μόνη της το δίκτυο ούτε αποδεικνύει επαναφορά σε νέο task. Ο ιδιοκτήτης χρειάζεται να ελέγξει και να αποθηκεύσει τις αλλαγές στις ρυθμίσεις περιβάλλοντος και στη συνέχεια να δημοσιεύσει το περιβάλλον. Η δημόσια έρευνα θα επαναληφθεί όταν η πρόσβαση εφαρμοστεί.

Η ενεργή ρύθμιση δικτύου εξακολουθεί να μην περιλαμβάνει τα τέσσερα πρόσθετα domains. Η πραγματική φωνητική υπηρεσία AI χρειάζεται επιλογή παρόχου και έγκριση ορίου κόστους· δεν ενεργοποιήθηκε από το νέο ορόσημο.

## Όρια της έκδοσης

- Δεν περιλαμβάνει επιβεβαίωση email, ανάκτηση κωδικού, κοινωνική σύνδεση ή σύστημα παραγωγικής αποστολής email.
- Δεν έχει ανοιχτό φωνητικό διάλογο AI, πλήρες πρόγραμμα A1–C2, τεστ κατάταξης, διοικητικό CMS ή πραγματικές συνδρομές.
- Η αποθήκευση στον server επιτρέπει κοινή πρόοδο σε συνεδρίες του ίδιου λογαριασμού. Η λειτουργία σε δύο πραγματικές συσκευές και δημόσιο HTTPS δεν θεωρείται επαληθευμένη χωρίς αντίστοιχη δοκιμή.
- Το manifest και η προσωρινή αποθήκευση στατικών αρχείων δεν εξασφαλίζουν εγκατάσταση σε κάθε συσκευή ή πλήρη λειτουργία χωρίς σύνδεση. Οι λογαριασμοί και η αποθήκευση προόδου χρειάζονται τον server.
- Δεν υπάρχει οργανωμένη ανθρώπινη εξυπηρέτηση, νομική πιστοποίηση GDPR ή έγκριση δημόσιας κυκλοφορίας.
