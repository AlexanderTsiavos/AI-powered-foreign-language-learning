# AI Language Academy

Εφαρμογή Ελληνικά → Αγγλικά για ιδιωτική δοκιμή ενηλίκων. Περιλαμβάνει **9 εισαγωγικά μαθήματα και 27 ασκήσεις**, αποθήκευση προόδου και επαναλήψεις. Δεν είναι πλήρες πρόγραμμα A1 ή υπηρεσία έτοιμη για δημόσια κυκλοφορία.

## Άνοιγμα σε Windows

1. Εγκατάστησε **Python 3.12 ή νεότερη**.
2. Κατέβασε και αποσυμπίεσε το `ai-language-academy.zip`.
3. Κάνε διπλό κλικ στο **`start-windows.bat`** μέσα στον φάκελο.
4. Κράτησε το παράθυρο ανοιχτό όσο χρησιμοποιείς την εφαρμογή.

Για εκκίνηση από **CMD**, άνοιξέ το μέσα στον φάκελο της εφαρμογής και γράψε:

```bat
py server.py
```

Στον browser άνοιξε **http://127.0.0.1:8000**. Δεν χρειάζονται κάρτα, κλειδί AI ή άλλες βιβλιοθήκες για τη βασική λειτουργία. Η πραγματική εκτέλεση σε Windows παραμένει προς δοκιμή.

Σε macOS/Linux: `python3 launch.py`. Απαιτείται και εκεί Python 3.12 ή νεότερη.

## Τι μπορείς να δοκιμάσεις

- Εγγραφή ενηλίκου, μαθήματα, διορθώσεις, πόντους και συνέχεια από εκεί που σταμάτησες.
- **Επαναλήψεις → Εξάσκηση όλων** για άμεση εξάσκηση. Η επιλογή **Για τώρα** δείχνει όσες έφτασαν στην ώρα τους. Οι επαναλήψεις δεν δίνουν επιπλέον XP.
- **Ρυθμίσεις → Δοκιμές γνώσεων**: αρχικό δείγμα έξι ερωτήσεων A1 και έλεγχος κάθε ενότητας μετά την ολοκλήρωση τριών μαθημάτων. Δεν πιστοποιούν επίπεδο CEFR και δεν ξεκλειδώνουν μαθήματα ή XP.
- **Ρυθμίσεις → Τα αιτήματα υποστήριξής μου** και **Ειδοποιήσεις και προτιμήσεις**. Τα αιτήματα μένουν σε αυτή την εγκατάσταση· δεν στέλνονται με email και δεν εξασφαλίζουν ανθρώπινη απάντηση. Οι ειδοποιήσεις εμφανίζονται μέσα στην ανοιχτή εφαρμογή, χωρίς email, SMS ή push.
- Αλλαγή ονόματος/κωδικού, ανάκληση άλλων συνδέσεων, εξαγωγή και διαγραφή λογαριασμού.

Ο **Καθηγητής AI** είναι απενεργοποιημένος μέχρι να ρυθμιστεί χωριστά ήδη εγκατεστημένο τοπικό μοντέλο. Δεν εγκαταστάθηκε ή δοκιμάστηκε πραγματικό μοντέλο. Η προαιρετική φωνή του browser δεν αποτελεί ζωντανό διάλογο AI ή αξιολόγηση προφοράς. Η πληκτρολόγηση παραμένει διαθέσιμη.

## Για τον ιδιοκτήτη

Η βάση με τους λογαριασμούς αποθηκεύεται στον φάκελο **`academy-data` δίπλα στον φάκελο της εφαρμογής**. Μην τη διαγράψεις για αναβάθμιση και μην την ανεβάσεις στο GitHub.

Κανένας λογαριασμός δεν γίνεται αυτόματα διαχειριστής. Οι απλές οδηγίες για δικαιώματα διαχειριστή, προσχέδια μαθημάτων και αντίγραφα ασφαλείας βρίσκονται στις [οδηγίες λειτουργίας](docs/OPERATIONS.md).

## GitHub και browser

Ο κώδικας βρίσκεται στο [GitHub](https://github.com/AlexanderTsiavos/AI-powered-foreign-language-learning).

Υπάρχει έτοιμη διαμόρφωση [Codespaces](https://codespaces.new/AlexanderTsiavos/AI-powered-foreign-language-learning?ref=main), με [ελληνικές οδηγίες](docs/CODESPACES.md). Ο σύνδεσμος δημιουργεί περιβάλλον εργασίας, όχι ήδη ενεργή ιστοσελίδα. Έλεγξε πρώτα τα δωρεάν όρια και τη χρέωση του GitHub. Δεν δημιουργήθηκε πραγματικό Codespace ούτε επαληθεύθηκε η προώθηση θύρας από αυτή την εργασία.

Η διεύθυνση `127.0.0.1` ανοίγει την εφαρμογή στον υπολογιστή όπου τρέχει. Η προεπισκόπηση του cloud και η πρόσβαση από δεύτερη φυσική συσκευή δεν έχουν επαληθευθεί. Δεν ενεργοποιήθηκε δημόσια φιλοξενία ή πληρωμένη υπηρεσία.

## Έλεγχοι και όρια

```sh
python3 -m unittest discover -s tests -v
```

Οι έλεγχοι χρησιμοποιούν προσωρινές βάσεις. Οι προαιρετικοί browser έλεγχοι χρειάζονται Playwright/Chromium, που δεν απαιτούνται για την απλή χρήση της εφαρμογής. Τα ακριβή αποτελέσματα και το ιστορικό βρίσκονται στο [TEST_PLAN.md](TEST_PLAN.md).

Στις **6 Νοεμβρίου 2026** πέρασαν **109 αυτοματοποιημένα tests και τέσσερα browser scripts**, μαζί με τις νέες λειτουργίες και την επαναφορά προσωρινής βάσης. Οι έλεγχοι AI χρησιμοποίησαν δοκιμαστικές αποκρίσεις, χωρίς πραγματικό μοντέλο.

Παραμένουν ανοικτά: πραγματικό μοντέλο και διάλογος AI, πλήρες A1–C2, επιβεβαίωση email/ανάκτηση κωδικού, πληρωμές, πραγματικές δοκιμές συσκευών και μικροφώνου, παραγωγικό HTTPS, διαδικασία ανθρώπινης υποστήριξης και νομική προετοιμασία. Η εφαρμογή αφορά ιδιωτική δοκιμή ενηλίκων.
